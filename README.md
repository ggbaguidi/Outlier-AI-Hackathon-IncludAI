## 🎯 Hackathon Challenge

**Level Up: Vibe Coding Hackathon**  
Reimagine a real-world site and build the features you’ve always wanted. We started from the live IncludAI DataHub landing page (only hero, features, partner logos, and footer) and developed seven full modules to transform it into a comprehensive web app.

**Submission Deadline:** Sunday, May 4 @ 11:59 PM PT  
**Submitted:** May 3, 2025

---

## 💡 What We Added

Starting from a **landing page only** implementation, we built and integrated the following modules:

1. **Centralized Dashboard**  
   – Live KPIs: total surveys, completion rate, bias alerts, active collectors  
   – Interactive choropleth map of response density  
   – Demographic breakdown charts & time-series trends  
   – AI-insights widget with bias-detection alerts

2. **Data Collection Module**  
   – Drag-and-drop survey builder (incl. Washington Group templates)  
   – Offline-capable mobile/web form with GPS capture  
   – Anonymization controls and multi-language support

3. **AI Analytics Engine**  
   – Automated cleaning and normalization pipelines  
   – ML models for service-gap detection & resource forecasting  
   – Natural-language report generator with PDF/CSV exports

4. **Co-Design & Feedback Portal**  
   – Suggestion forms & validation workflows for disability communities  
   – Versioned feedback timeline and contributor directory  
   – Workshop scheduling and invite flows

5. **Reporting & Data-as-a-Service (DaaS)**  
   – Custom report builder with drag-and-drop filters  
   – Developer-friendly REST API & key management  
   – Tiered subscription management (Idea / Build / Scale phases)

6. **User & Access Management**  
   – Role-based permissions (Admin, Collector, Analyst, Guest)  
   – Two-factor authentication toggle & audit logs for compliance

7. **Partnerships & Resources Hub**  
   – Directory of partners, advisory board & data sources (WHO, Sightsavers…)
   – Resource library: best-practice guides, policy briefs & SDG maps

## 🛠 Tech Stack

- **Frontend:** HTML5, Tailwind CSS, Font Awesome, Google Fonts, Vanilla JS  
- **Charts & Maps:** Chart.js (prototype), Leaflet for choropleth  
- **Backend Stubs:** Simulated with JS redirects (login → dashboard)  
- **AI/ML (planned):** Python (scikit-learn, Pandas) for data pipelines

> **Note:** This hackathon submission focuses on front-end prototypes. Backend and AI scripts are planned next.

## 🚀 How to Run Locally

1. **Clone the repo**  
   ```bash
   git clone https://github.com/ggbaguidi/Outlier-AI-Hackathon-IncludAI.git
   cd Outlier-AI-Hackathon-IncludAI
   ```

2. **Serve files**  
   ```bash
   npx serve .
   ```

3. **Explore**  
   - **Landing**: `index.html`  
   - **Login**: `login.html` → redirects to `dashboard.html`  
   - **Modules**: Access via header nav links
